# mobile-work

Workspace for driving Claude Code from a phone — via **SSH into the home PC**, or the **Claude Code web/mobile app** through GitHub.

- **What it's for:** on-the-go code, writing, art-pipeline control, and scratch work.
- **How to connect:** see [CONNECTING.md](CONNECTING.md).
- **How Claude should work here:** see [CLAUDE.md](CLAUDE.md).

Structure is deliberately minimal and grows as needed. Model weights, large media, and secrets are gitignored — the heavy art workspace stays on the PC at `ComfyUI-Shared`.
